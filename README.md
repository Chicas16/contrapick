# Wild Rift MX — Ayuda de builds

Sitio estático (HTML/CSS/JS) en español (México): eliges campeón + rol + 5 enemigos y recibes botas, núcleo y situacionales con una razón corta ligada al equipo rival.

**Beta.** Builds aproximados. Proyecto fan **no afiliado a Riot Games**.

## Demo

GitHub Pages: https://chicas16.github.io/wildrift-mx/

## Desarrollo

Abre `index.html` o sirve la carpeta. Prueba el motor:

```bash
node test-rules.js
```
